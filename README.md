# miyakago

宮崎・鹿児島ツーリングしおり LP サイト（静的HTML）

- `index.html` — LPトップ（しおり画像 + 詳しい旅程への導線）
- `itinerary.html` — 詳しい旅程（ブログ風・1日目/2日目の全スポット詳細）
- `assets/img/` — LP掲載画像
- `assets/css/style.css` — スタイル
- `assets/js/main.js` — スクロール連動の「トップへ戻る」ボタン制御

ローカル確認: リポジトリ直下で `python3 -m http.server 8080` などを実行し `index.html` を開いてください。
