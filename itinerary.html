日南海岸〜都井岬〜鹿屋市へ

青い海と南国の風を感じる絶景ルートを南下！

🏍️ 走行距離 約146km ⏱️ 走行時間 約2時間44分 📷 おすすめ立ち寄りスポット
  1. START

    宮崎港

    朝、フェリーを下船。ツーリングスタート！

  2. 約30分（約20km）

    道の駅フェニックス

    日南海岸を代表する絶景スポット！青い海とヤシ並木が広がる最高のロケーション。

    おすすめポイント

    • 太平洋を一望できる展望デッキ
    • 名物！マンゴーソフトクリーム
    • お土産や地元グルメも充実
  3. 約45分（約35km）

    道の駅なんごう

    南国ムードあふれる道の駅。高台からの絶景や、宮崎のフルーツ・お土産が充実！

    おすすめポイント

    • 高台からの海岸線の眺めが抜群
    • マンゴーなどフルーツが豊富
    • 休憩＆ランチスポットに最適
  4. 約40分（約30km）

    都井岬

    野生の御崎馬が暮らす岬。開放的な草原と太平洋のコントラストが絶景！

    おすすめポイント

    • 御崎馬との出会い
    • 雄大な岬の景色と灯台
    • 水平線まで見渡せる大パノラマ
  5. 約40分（約31km）

    鹿屋市（宿泊地）GOAL

    日南海岸を堪能したあとは、鹿屋市へ。温泉やグルメで1日の疲れをリフレッシュ！

    おすすめポイント

    • 大隅半島の中心都市
    • カンパチ、黒豚などグルメも◎
    • 温泉・入浴施設も充実

✔ 日南海岸の太平洋ブルーを満喫できるルート！

✔ 絶景スポットが多く、写真好きライダーにもおすすめ！

宿泊先

    無料駐車場（バイクOK）

  • ♨️
    男性専用スパ・大浴場

    ツーリングの疲れを癒せる大浴場＆サウナあり！

  • 🛏️
    快適な客室

    清潔で落ち着いたお部屋でゆっくり休めます。

2日目

桜島一周ツーリング

桜島をぐるっと一周！ダイナミックな景色を満喫！

🏍️ 走行距離 約129km（桜島一周 約35km） ⏱️ 走行時間 約2時間35分（観光・休憩含め半日〜1日） 📷 おすすめ絶景ルート
  1. START

    ビジネスホテルしらさぎ（鹿屋市）出発

    朝食後、出発！

  2. 約20分（約12km）

    道の駅たるみず

    桜島を目の前に望む絶好の休憩スポット！約100mの足湯でリフレッシュ、錦江湾と桜島の絶景、カンパチの漬け丼や海鮮もおすすめ。

    おすすめポイント

    • 桜島が目の前に広がる！
    • 足湯でひと休み
    • 地元グルメやお土産が充実
  3. 約15分（約10km）

    桜島フェリーで桜島へ

    鹿児島市街地を望みながらフェリーで桜島へ渡ります。

    おすすめポイント

    • 約15分の船旅
    • 錦江湾と鹿児島市街の景色
    • フェリー運賃は公式サイトで確認
  4. 約15分（約8km）

    湯之平展望所

    桜島の最高地点にある展望所。標高373mからの大迫力の景色、火口や荒々しい山肌を間近で体感。

    おすすめポイント

    • 火口を間近に望む迫力
    • 錦江湾と鹿児島市街を一望
    • 売店や軽食コーナーもあり
  5. 約15分（約7km）

    有村溶岩展望所

    大正噴火で生まれた広大な溶岩原。ゴツゴツした黒い溶岩の大地、錦江湾と桜島のコントラストが絶景。

    おすすめポイント

    • 迫力ある溶岩原を散策
    • 海と火山の景色が最高
    • 写真映えスポット多数
  6. 約60分（約35km）

    桜島一周ツーリング

    外周約35kmの爽快ルート！海沿いの道や溶岩地帯を巡り、潮風とダイナミックな景色を満喫。

    おすすめポイント

    • 景色が次々変わる楽しいルート
    • 火山・海・自然を一度に体感
    • バイクとの相性抜群！
  7. GOAL

    志布志方面へ GOAL

    桜島を後にして、志布志港へ。フェリー乗船までゆっくり準備を。

この日のポイント

✔ 桜島の絶景スポットをしっかり巡る

✔ 余裕を持って志布志港へ向かう

✔ 給油・休憩は早めに！
